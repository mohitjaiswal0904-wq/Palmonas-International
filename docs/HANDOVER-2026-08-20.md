## Catalogue model (important)

### Seeds

- **File:** `src/data/catalog/products.seed.ts`
- Prices authored in **INR**, converted with `inrToUsd(inr)` (`÷ 83.5`) so India region display stays accurate.
- Metals:
  - Ode To Nature: `silver` + `yellow` (plated finish label)
  - 9KT Gold: `gold9k` + `white` + `rose` (personalisation tones)
- Stones: `cz` (silver) · `lab-diamond` (gold)

### Builder

- **File:** `src/data/catalog/products.ts`
- `materialsFor()` switches materials string by metal family (don’t hardcode sterling for gold).
- Images still come from `CATEGORY_IMAGERY` (generated placeholders), **not** live CDN product photos yet.

### Taxonomy / types

- `src/types/catalog.ts` — `CollectionSlug` includes `ode-to-nature` | `9kt-fine-gold`
- `src/data/catalog/taxonomy.ts` — labels + nav aliases (`gold-jewellery` → `9kt-fine-gold`)
- `src/data/catalog/collections.ts` — collection marketing copy

### Demo orders

- `src/data/commerce/orders.ts` references **new** product ids. Adding/removing seeds may break `productById` at boot — update order lines accordingly.

### Re-syncing from palmonas.com

There is no automated importer in-repo. Previous sync used Shopify JSON + PDP HTML:

1. Collection: `https://palmonas.com/collections/{handle}/products.json?limit=250`
2. Product body + metafields / `px-kv` detail rows from the live PDP HTML
3. Loox widget shows store-wide **4.6 / 66098** on these SKUs (not SKU-level reviews)

If you re-scrape, preserve site spelling (e.g. “Nector Mayfly”, “Rosegold”) unless product asks for copy edits.

## Feature notes by surface

### PLP (`PlpView`)

- Sticky filter/sort under header
- Custom sort menu (not native `<select>`)
- Filter drawer width aligned with wishlist (`max-w-[440px]`)
- Metal/stone chips include 925 silver, 9KT, lab diamond, CZ

### Product card / wishlist button

- Heart sits in image top-right (`right-3 top-3`), no circular chip
- Default `fill-white` stroke; filled ink when wishlisted
- Button is **outside** the product `Link` (no nested interactive)

### Cart drawer

- Removing a line (or qty → 0) opens confirm: Move to wishlist / Remove / Keep in bag

### Wishlist drawer

- Chips: All | Gold (`gold9k`) | Silver | Demifine (plated / non–solid-gold)

### PDP (`ProductBuyPanel` + page)

- Breadcrumbs removed
- Mobile: title + price only in sticky bottom bar; panel uses `sr-only` h1
- Description removed from buy panel (still in `ProductDetails`)
- Size guide → `/size-guide`
- Story: full-bleed image on mobile; outline `ButtonLink` CTA
- Craft + Material editorial blocks removed

### Footer & info

- Footer data: `src/data/content/footer.ts`
- Page bodies: `src/data/content/infoPages.ts`
- Shared view: `src/components/content/InfoPageView.tsx`
- Routes: `/policies`, `/policies/[slug]`, `/about`, `/contact`, `/stores`, `/blogs`, `/size-guide`

3. **Blogs** — stub page only.
4. **Support / Careers** — may still 404 if linked from older nav.
5. **Reviews** — Loox store aggregate used; not per-SKU review feeds.
6. **Ring sizes** — some silver rings use Shopify’s published sizes only (e.g. 6/7); others fall back to a wider size list when the store uses `Default Title`.
